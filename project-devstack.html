Dev Stack – Technology Management App

A responsive app for exploring technologies and managing your own stack, with duplicate prevention and toast feedback.

GitHub Repository

Brief Description

Dev Stack is a small, responsive React application for exploring technologies and building a personal stack. Users can add and remove technologies, and the app prevents duplicates and confirms every action with a toast notification.

Main Technology Stack

ReactTypeScriptTailwind CSSVite

Key Features

  • Explore a catalog of technologies.
  • Add and remove technologies from your stack.
  • Duplicate prevention.
  • Toast notifications for every action.
  • Fully responsive layout.

Project Links

Live project: No live demo — this is a code/research project. See the GitHub repository.

GitHub repository: https://github.com/jferdous222318/Assignment05

Challenges Faced

  • State management. Keeping the catalog and the user's stack in sync as items are added and removed.
  • Duplicate prevention. Checking for existing items reliably and explaining the result to the user.
  • Clear feedback. Giving instant, non-intrusive feedback with toast messages.

Potential Improvements & Future Plans

  • Save stacks to a database with user accounts.
  • Search and filter by category.
  • Drag-and-drop ordering.
  • Share a stack through a public link.
