StudioSpace – Creative Studio Booking Marketplace

A full-stack marketplace where hosts list creative studios and guests book them, with secure login and double-booking prevention.

Live Demo ↗ GitHub Repository

Brief Description

StudioSpace is a peer-to-peer marketplace for booking creative spaces such as photo studios, sound stages, podcast rooms, and art workshops. Hosts can publish and manage their own studio listings, while guests can search, filter, and book a space with a live price summary.

Main Technology Stack

Next.jsTailwind CSSdaisyUISwiperReact Hot ToastExpress.jsMongoDBJWTbcrypt

Key Features

  • Email/password and Google authentication using JWT stored in HTTPOnly cookies.
  • Search, filter, and sort for studios.
  • Host listing management: add, update, and delete studios.
  • Host booking dashboard to follow incoming bookings.
  • Booking system with a live price summary and double-booking prevention.

Project Links

Live project: https://studiospace-black-ten.vercel.app/

GitHub repository: https://github.com/jferdous222318/studiospace

Challenges Faced

  • Preventing double bookings. Two people can request the same studio and time at once, so the booking logic had to check availability on the server before confirming.
  • Secure authentication. Keeping sessions safe with JWT in HTTPOnly cookies between the Next.js client and the Express server, while supporting both email/password and Google sign-in.
  • Host and guest roles. Separating what hosts can manage (listings, bookings) from what guests can do, without duplicating logic.
  • Live price summary. Keeping the displayed total correct as dates, hours, and options change.

Potential Improvements & Future Plans

  • Online payment integration.
  • Reviews and ratings for studios and hosts.
  • Calendar view of availability and booking sync.
  • Image upload for studio listings.
  • Email notifications for booking updates.
  • Admin panel for moderation and reports.
