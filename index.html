My journey

My programming journey began with Computer Science and Engineering at United International University, where I built a foundation in C, C++, data structures, object-oriented programming, SQL, and Python. Curious about how real products are made, I moved into web development with JavaScript, React, and Next.js, then added Node.js, Express.js, and MongoDB to build complete full-stack applications.

What I enjoy building

I enjoy building features end to end: a clean interface, a REST API behind it, and a database that stores the data safely. Authentication, booking logic, and data-driven dashboards are my favourite kinds of problems, because they need careful thinking as well as attention to the user experience.

Beyond the code

Outside of coding, I like learning new tools, understanding how things work, and breaking big problems into small steps. I am curious, patient, and a steady learner who enjoys explaining ideas in simple words.

I am looking for an entry-level opportunity in software development, IT support, or technical support, where I can keep learning and contribute to real projects.
